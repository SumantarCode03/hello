# Amazon Homepage Clone

This project is a static clone of the Amazon homepage built using HTML and CSS. It demonstrates a responsive frontend layout mimicking the iconic e-commerce website structure.

## Features

- **Navigation Bar**: Includes a logo, delivery location, search bar, sign-in, returns/orders, and a shopping cart icon.
- **Hero Section**: A large banner area showcasing promotions or featured content.
- **Shop Sections**: Multiple grid boxes displaying various product categories like Top Deals, Electronics, Health & Personal Care, etc.
- **Footer**: A comprehensive footer featuring links to "Get to Know Us", "Make Money with Us", "Amazon Payment Products", and "Let Us Help You".

## Technologies Used

- **HTML5**: For structuring the webpage elements.
- **CSS3**: For styling, layout, and visual presentation.

## Setup & Run

1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser to view the project.

## Project Structure

- `index.html`: The main HTML file containing the structure of the homepage.
- `style.css`: The stylesheet containing the design and layout rules.
- Assorted image files (`*.jpg`, `*.png`) used as assets within the webpage layout.
